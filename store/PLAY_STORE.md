## Release steps
1. Pay the one-time USD 25 fee and create a developer account at https://play.google.com/console.
2. Create app → enter the details above.
3. Testing → Closed testing → Create release → upload `india-run-playstore.aab` from the GitHub release.
4. New personal developer accounts (created after 13 Nov 2023) must keep at least 12 testers opted in to this closed test for 14 days in a row before they can apply for production. Testers join through the Play testing link (not by installing the APK). Internal testing does not count.
5. Production → Create release → upload the AAB → Submit for review.
